# Emails (Brevo)

Source for the class emails sent through Brevo.

- `*.brevo.yaml` — paste into Brevo's drag-and-drop editor in **developer mode** (Brevo takes its own YAML block format, not raw HTML).
- `*.html` — standalone HTML version of the same email, for previewing.

| File | Used for |
|---|---|
| `fall-2026-class-starts-tomorrow.*` | Reminder the day before Class 1 (Fall 2026) |
| `mailing-list-welcome.brevo.yaml` | "You're on the list" confirmation for the website signup form |
